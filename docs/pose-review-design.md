2026-10-02，用户授权：老三本地识别人和动作；每 30 秒在老大 Mini 临时目录保存关键点、人物和动作标注照片，供人工检查，不上传。

2026-10-04，用户追加授权：在已登录的主控台查看照片、识别信息并人工修改人物和分类；人工确认结果单独保存在 Mini，供后续模型调优和训练。照片不上传到外部服务。

2026-10-04，用户调整采样额度：每天最多成功采集 50 张，达到上限后当天停止，第二天自动恢复。自然日固定按 Asia/Singapore（UTC+8）计算；每张原片、审核图与 JSON 合计为一个样本，不把三个文件分别计数。原有每 30 秒至多一张、仅有人时保存的规则保留。

## 每日额度

- 每日额度持久保存在 Mini 私有 `state/sampling-quota/quota.sqlite3`，目录 0700、账本与锁文件 0600；服务重启和删除照片不会释放已使用的额度。首次启用只读取采样元数据，按样本 ID 去重原始采样、已保留训练样本和回收区副本，根据已提交 JSON 中的 sampled_at 转换到新加坡日期，计入当天历史样本；已有样本超过 50 时当天立即停止，保留历史照片。迁移限制为最多 20,000 份元数据、总计 64 MiB。
- 保存前在同一跨进程互斥范围中检查额度，提交完成后记录成功计数；中断操作有可恢复记录，失败不算作成功，损坏计数或存储失败时暂停保存并显示原因，避免多实例竞争超额。
- 当天第 50 张成功后停止自动照片采样，新加坡午夜重置为新一天的 50 张额度。达到上限时停止无人观看的后台视频租约，手动实时视频仍可打开；新一天自动恢复后台采样。
- 状态接口和页面显示日期、时区、今日已采集数量与每日上限，达到上限显示“今日额度已用完，明日自动恢复”。历史数据首次迁移可显示超过 50 的旧数量；不删除超额照片。
- 保存使用持久预留记录。重启时有完整三文件提交或可验证删除标记的记录只计一次；中断记录无法确认是否成功时，当天暂停采样并保留审计，次日恢复。账本损坏或路径不安全时保持暂停，界面不把未初始化的数量显示为零。

## 实现契约

- 复用 Pi 代理唯一 V4L2 采集器。独立低优先级进程运行 MediaPipe Pose Landmarker Lite，最多三人；每次处理最新帧，CPU 推理不进入控制事件循环。不允许模型驱动电机。
- 固定模型、Python 依赖版本；原生推理依赖独立 pose-venv，控制服务依赖不受影响。进程以长度前缀 JPEG 输入、JSON 输出，无网络、无相机访问；超时终止并退避重启。
- Pi 输出 33 个归一化关键点、可见度、人物临时跟踪编号、姿态、动作、推理耗时。保留来源 sequence/timestamp_ns；JPEG 与结果必须属于同一帧。推理失败显示 unavailable，不复用旧骨架。
- 站/坐/躺/蹲使用几何启发式与连续确认；蜷缩仅为候选，尚无家庭训练样本。挥手基于身体相对坐标的连续往复，抬手不等同挥手。遮挡时输出无法判断。规则得分不是校准后的准确率。
- Mini 仅调用现有 loopback 人脸服务，用同一帧的人脸与头部位置进行唯一匹配，不跨帧继承身份，无法唯一匹配时标为未确认。
- 已明确授权后台采集，不依赖浏览器会话。后台视频租约与浏览器观看分离；登出撤销浏览器访问和控制，不停止配置中明确开启的审核采集。断线时摄像头租约过期停止，重连自动恢复。
- Mini 定时采样每 30 秒至多一张最新的完整识别帧；2026-10-03 按用户修订：只有同帧有效的人体骨架或人脸结果非空才保存。无人直接跳过并清除待保存旧帧，不占用 30 秒间隔；人物身份未确认或动作未知也可以保存。来源过期/离线不保存旧照片。
- 默认关闭，通过 CONSOLE_POSE_REVIEW_DIR 显式开启。部署使用 /Users/agent001/workspace-agent/deploy/ai-tv-pet-console/tmp/pose-review。审核目录与 originals 子目录为 0700，JPEG/JSON 为 0600，无公共静态路由、无云上传、无照片写入 Git。照片列表、图片与人工标注仅通过 admin 登录后的专用接口访问，修改需 CSRF 校验；原有本地 Finder 查看方式仍可用。
- 新采样同时保存无叠加原片 originals/{stamp}.jpg、主目录标注 JPEG 和同名 JSON。原片逐字节保留同一来源帧的 JPEG，不进行重编码；JSON 增加 original_available=true 和 original_image=originals/{stamp}.jpg。来源元数据仍包含本机采样时间、序号/单调时钟、模型、关键点、分类规则版本、姓名匹配与服务状态。中文文字用本地字体。旧照片只有标注图，无法还原原片，页面应明确标明历史样本无原片，不伪造无标注图。
- 三个文件先以独占创建的 0600 临时文件写入和刷盘，再原子替换；JSON 最后发布，作为完整样本的提交标志。任一写入或发布失败均清理本次临时文件与已发布文件，不覆盖或删除旧样本。拒绝审核目录、原片目录、目的文件或临时文件的符号链接；读取原片按受限样本 ID 生成固定路径，不信任 JSON 中的任意路径。保存失败可见，不阻塞推理/控制。
- 采样存储上限 2 GiB，保存前将新原片、标注图和 JSON 的实际总字节计入；预计保存后剩余空间少于 1 GiB 时暂停保存，保留已有样本，不自动删除。来源 JPEG 延续协议的 1 MiB 上限。停用方法：清除环境变量并重启 console。
